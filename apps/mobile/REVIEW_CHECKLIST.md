# Review Guidelines Checklist

## Pre-submission Checklist
1.  **Sign in with Apple**: If Social Login (Google) is present, 'Sign in with Apple' must be implemented.
2.  **No Hidden Features**: Ensure no hidden features are unlocked via QR code (violates In-App Purchase rules).
3.  **Account Deletion**: Verify that the 'Delete Account' button is visible and functional within app settings.
4.  **Privacy Policy**: Ensure the privacy policy URL is accessible and up-to-date.
5.  **User Generated Content**: If applicable, ensure reporting/blocking mechanisms are in place.
6.  **IPv6 Support**: Ensure the server supports IPv6 (Apple requirement).
7.  **Data Collection**: Accurately declare data collection in App Store Connect.
