## 1. Onboarding a Student

To add a new student to the system:

1.  Navigate to **Admission** > **Applications**.
2.  Click **"New Application"**.
3.  Fill in the required details:
    *   **Student Info**: First Name, Last Name, DOB, Gender.
    *   **Class Selection**: Choose the admission session and target class (e.g., Grade 1).
    *   **Parent Info**: Mobile Number (Critical for login), Name.
4.  Upload Documents (Birth Certificate, Transfer Certificate).
5.  Click **"Submit & Matriculate"**.
    *   *Note: This will automatically create the Parent Account and Student Fee Ledger.*

## 2. Generating Fee Receipts

When a parent pays fees in cash or cheque:

1.  Go to **Finance** > **Fee Collection**.
2.  Search for the student by Name or Admission Number.
3.  Select the **"Collect Fee"** button next to the student.
4.  Enter the Amount and Payment Mode (Cash/Cheque/DD).
5.  (Optional) Enter Transaction ID / Cheque Number.
6.  Click **"Record Payment"**.
7.  A PDF Receipt will be generated instantly. Click **"Print"** or **"Email to Parent"**.

## 3. How to Reset Passwords

If a staff member or parent forgets their password:

1.  Navigate to **User Management** > **Users**.
2.  Search for the user by Email or Phone.
3.  Click the **"Edit"** (Pencil) icon.
4.  Click **"Reset Password"**.
5.  Choose one:
    *   **Send Reset Link**: Sends an email/SMS to the user.
    *   **Set Temporary Password**: Manually enter a password (e.g., `Welcome@123`) and communicate it securely.
6.  Click **"Save"**.
