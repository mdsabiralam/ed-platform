# Support Portal Configuration & Tiers

## Overview
We have initialized a Help Desk system (e.g., Freshdesk/Zoho Desk) to manage customer support. Below is the configuration for the three support tiers.

## Support Tiers

### Tier 1: Automated / Self-Service (L1)
- **Agent:** Chatbot / Knowledge Base
- **Scope:** Common FAQs, Password Resets, Basic Navigation.
- **Workflow:**
    1.  User initiates chat or search.
    2.  Bot analyzes intent (e.g., "Forgot Password").
    3.  Bot provides relevant Knowledge Base article or performs automated action (if authenticated).
    4.  If unresolved, option to "Talk to an Agent" is presented.

### Tier 2: Support Agent (L2)
- **Agent:** Customer Support Team
- **Scope:** Login issues, Data Sync problems, Fee Payment failures, User Onboarding assistance.
- **Tools:** Helpdesk Dashboard, Admin Panel (Read-only access).
- **Workflow:**
    1.  Ticket is created from L1 escalation or email.
    2.  Agent investigates using the Admin Panel.
    3.  Agent replies with resolution or workaround.
    4.  **Target Response Time:** < 1 hour.

### Tier 3: Engineering Escalation (L3)
- **Agent:** Engineering Team (DevOps / Backend)
- **Scope:** Software Bugs, Server Errors (500), Data Corruption, Security Incidents.
- **Integration:** Jira.
- **Workflow:**
    1.  L2 Agent reproduces the issue and tags it as a "Bug".
    2.  Ticket is automatically synced to Jira project `ED-PLATFORM-BUGS`.
    3.  Engineering team triages and fixes the issue.
    4.  Status update in Jira reflects back to the Helpdesk ticket.
