# User Manual: School Admins

## 1. How to Onboard a Student

**Prerequisites:**
- Ensure you have the `SCHOOL_ADMIN` or `ADMISSION_MANAGER` role.
- Collect necessary documents (Birth Certificate, Transfer Certificate, etc.).

**Steps:**
1.  **Navigate to Admission Module:**
    - Log in to your dashboard.
    - Click on "Admissions" in the sidebar.
    - Select "New Application".
2.  **Fill Student Details:**
    - Enter First Name, Last Name, Date of Birth, and Gender.
    - Select the Class to Apply for.
3.  **Parent/Guardian Information:**
    - Enter Parent Name, Email, and Phone Number.
    - *Note:* If the parent already exists in the system (by phone number), they will be linked automatically.
4.  **Upload Documents:**
    - Upload scanned copies of required documents in PDF or JPEG format.
5.  **Submit & Matriculate:**
    - Click "Submit Application".
    - Review the application.
    - Click "Matriculate" to finalize admission. This will generate the Admission Number and create the Student record.

## 2. How to Generate Fee Receipts

**Steps:**
1.  **Navigate to Finance Module:**
    - Go to "Finance" -> "Fee Collection".
2.  **Search Student:**
    - Enter the Student Name or Admission Number in the search bar.
3.  **Select Invoices:**
    - View pending invoices for the student.
    - Select the invoices being paid.
4.  **Record Payment:**
    - Click "Collect Fee".
    - Enter the Amount, Payment Mode (Cash, Cheque, Online), and Reference Number (if applicable).
    - Click "Confirm".
5.  **Print Receipt:**
    - Once confirmed, a "Print Receipt" button will appear.
    - Click to generate and download the PDF receipt.

## 3. How to Reset Passwords

**Steps:**
1.  **Navigate to User Management:**
    - Go to "Administration" -> "Users".
2.  **Locate User:**
    - Search for the user by email or name.
3.  **Reset Action:**
    - Click the "Actions" menu (three dots) next to the user's name.
    - Select "Reset Password".
4.  **Choose Method:**
    - **Send Reset Link:** Sends an email to the user with a link to set a new password.
    - **Manual Reset:** Allows you to set a temporary password manually (e.g., `Welcome@123`).
5.  **Confirm:**
    - Confirm the action. Advise the user to change their password upon first login.
