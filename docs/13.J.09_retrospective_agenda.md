# Post-Launch Retrospective: Agenda

**Date:** [Date + 48 Hours from Launch]
**Time:** 10:00 AM - 11:30 AM
**Attendees:** Engineering, Product, QA, DevOps

## 1. Introduction (5 mins)
- Brief overview of the launch timeline.
- Acknowledgement of team effort.

## 2. Quantitative Review (15 mins)
- **Uptime:** Was the 99.9% SLA met?
- **Load:** Peak concurrent users vs. Expected (50k).
- **Performance:** 95th percentile response times.
- **Support Volume:** Total L1/L2 tickets created.

## 3. What Went Well? (20 mins)
*Open floor for positive feedback. Examples:*
- "Mobile App Sync worked flawlessly even offline."
- "Database CPU stayed below 40%."
- "Deployment pipeline was smooth."

## 4. What Didn't Go Well? (20 mins)
*Constructive criticism. Examples:*
- "E2E tests were flaky during pre-checks."
- "SMS delivery had a 2-minute lag."
- "Staff onboarding took longer than expected."

## 5. Root Cause Analysis (15 mins)
- Deep dive into any critical incidents (P0/P1) that occurred.
- "Why did the SMS gateway lag?"

## 6. Action Items for Phase 2 (15 mins)
- Prioritize fixes for "What didn't go well".
- **Proposed Features:**
    - Implement Graph Database for social features.
    - Optimize Notification Engine.
    - Automate Staff Onboarding via CSV.

## 7. Closing (5 mins)
- Assign owners to action items.
- Schedule next sprint planning.
