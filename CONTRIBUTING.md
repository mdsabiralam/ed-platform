# Contributing to ed-platform

We welcome contributions from the community. Please follow these guidelines to ensure a smooth development process.

## Coding Standards

- **Code Style:** Follow the existing code style. We use Prettier for automatic code formatting.
- **Commit Messages:** Follow the [Conventional Commits](https://www.conventionalcommits.org/) specification.
- **Branching:** Create a new branch for each feature or bug fix. Use a descriptive branch name (e.g., `feat/add-user-authentication` or `fix/login-button-bug`).
- **Pull Requests:** Open a pull request to the `main` branch. Provide a clear description of the changes and link to any relevant issues.

## Development Process

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Run the tests.
5. Open a pull request.
